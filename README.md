# 小桌宠（desktop-pet）

## 一、这是什么

一只住在 Windows 桌面上的像素风小宠物：

1. **桌宠本体**：透明小窗挂在屏幕上，可以拖拽，有浮动、眨眼、点击弹跳等小动作
2. **AI 问答**：点击桌宠弹出聊天框，接入免费大模型（GLM-4-Flash）进行简单问答
3. **形象定制**：上传任意图片自动转成 64×64 像素风；照片可以裁出头像区域，并用像素编辑器点格子手动微调

个人使用 + 开源到 GitHub。纯本地应用：无后端、无数据库、无账号系统。

## 二、技术选型（已定，不要轻易更换）

| 事项 | 选择 | 理由 |
|---|---|---|
| 运行框架 | Electron（HTML/CSS/JS） | 生态成熟、前端技术上手快，最终可打包成 exe |
| AI 对话 | 智谱 GLM-4-Flash（免费） | 国内直连、注册即有 key、OpenAI 兼容接口 |
| 图像像素化 | 纯本地算法（缩放 + 色彩量化） | 免费、秒出、稳定，不依赖任何 AI 服务 |
| 数据存储 | 本地文件夹（PNG + JSON） | 无需数据库 |

## 三、功能需求明细

### 1. 桌宠本体

- 无边框透明窗口，总在桌面最前
- 鼠标可拖拽到屏幕任意位置，**位置记忆**（重启后回到原地）
- 程序动画（单张静态图 + 代码变换实现）：待机浮动、左右摇摆、被拖拽时倾斜、点击弹跳、定时眨眼
- **左键点击 = 拍拍反应**（眯眼笑 + 弹跳 + 头顶冒像素爱心）；**右键点击 = 快捷菜单，只保留两项：聊一聊 / 设置**
- **设置窗口是统一的个性化入口**：换形象（含上传图片）、改名字、编辑人设提示词、调整显示大小，全部收在这里
- 最小化到系统托盘，托盘右键菜单（设置 / 退出）

### 2. AI 聊天

- 点击桌宠弹出聊天气泡小窗
- 调用 GLM-4-Flash 完成简单问答（OpenAI 兼容接口）
- 聊天时桌宠播放"说话"反应（程序动画即可）
- **人设（提示词）跟随形象**：存在每个形象的 `pet.json` 的 `persona` 字段里，换形象即换人设
- **设置窗口（统一个性化入口）**：换形象、改名字、编辑人设提示词、调整显示大小，保存即生效
- **聊天支持截图**：在聊天框 Ctrl+V 粘贴截图（或拖入图片文件），带图消息自动切换到免费的视觉模型 GLM-4V-Flash 看图说话，纯文字消息仍走 GLM-4-Flash
- **聊天框头像跟随当前形象**，对话气泡可悬停单条删除（AI 同步忘记这句）
- API key 存在本地 `config.local.json`，**永远不提交到 Git**

### 3. 形象定制

- 每个形象 = 一个文件夹：`sprite.png`（默认 64×64）+ `pet.json`（名字、尺寸、配色、动画参数）
- 内置默认形象：用代码逐格画一只像素小猫，不依赖任何外部图片资源
- 上传任意图片 → 自动缩放到 64×64 + **色彩量化**（把颜色收敛到有限调色板，这是"像素味"的关键一步）
- **全身照也能像素化**：容差抠背景（自动取四边背景色，把相近的连通区域变透明，容忍度可调）+ 拖框裁剪人物范围；照片建议用纯色背景，复杂背景可以先用手机/修图工具的抠图功能预处理后再上传
- 照片形象的托盘图标自动裁成圆形透明头像
- 照片 → 手动框选裁出头像区域 → 像素化
- 16 倍放大像素编辑器：点格子改颜色 + 橡皮擦（补抠背景、修细节），手动微调
- 多形象管理：列表、切换、删除

**明确不做**（已砍掉的需求，防止以后被带偏）：

- ❌ AI 生成像素图（文生图 / 图生图路线）
- ❌ AI 生成多帧动画图集（AI 多帧一致性差；动画全靠程序变换）
- 人物形象只求"大致能看出是谁"（发型、穿搭、配色神似），不做五官级相似

## 五、打包与安装（npm run dist）

1. `npm run dist` —— 产物在 `release/` 里：
   - `DesktopPet-x.x.x-Setup.exe`：安装包（可选安装目录，带卸载器）
   - `win-unpacked/小桌宠.exe`：绿色版，双击直接跑
2. 安装版的数据（形象库 / 位置 / API Key）放在 `%APPDATA%\小桌宠\`，和开发环境互不干扰
3. 装好后第一次聊天会提示配置 Key：右键桌宠 → 设置 → **API 设置**，粘贴智谱 Key（注册即送）即可
4. 发 GitHub Release：仓库页 → Releases → Draft a new release → 把 `Setup.exe` 拖上去 → Publish

```
小桌宠/
├── README.md            # 本文件：总体计划 + 进度
├── .gitignore           # node_modules / 密钥 / 打包产物 / 运行时生成物

├── renderer/            # 各界面
│   ├── pet.html         # 桌宠本体
│   ├── chat.html        # 聊天小窗
│   ├── settings.html    # 设置窗口（形象/名字/人设/大小，统一个性化入口）
│   ├── pixelize.html    # 上传图片像素化窗口（阶段 3）
│   └── editor.html      # 像素编辑器（阶段 4）
├── tools/render-preview.js  # 开发用：把猫渲染成 PNG 预览图，检查画得可不可爱
├── assets/pets/         # 形象库：每个形象一个文件夹（sprite.png + pet.json，首次运行自动生成）
```

## 七、常见坑（遇到了再看）

- **npm / Electron 下载慢或卡住**：国内网络常见，不是配置错误。设置国内镜像（npm 用 npmmirror，Electron 用 `ELECTRON_MIRROR` 环境变量，本项目 `.npmrc` 已配好），一分钟解决。
- **push 卡住或超时**：GitHub 在国内访问时好时坏，重试几次即可。
- **打包 exe 报错**：先尝试把项目移到纯英文路径（如 `D:\projects\desktop-pet`）再打包。
- **越改越乱**：说明该回退了——用 `git log` 找到上一个能跑的存档点回退重来，不要恋战。
